# Cook-Book
This is a recipe site I made with the theMealDB api, using React, Vite and Tailwind for styling. I made a home page that displays the first recipes (alphabetically) of the api, and also the same but filtering only the vegetarian ones right under. I made a search page to look for a specific recip with it's title or main ingridient. All of the recipes are clickable, clicking on them will take you to the instructions, some of them include a link to a tutorial video. I also made a login/signup page that's made functional with supabase.
